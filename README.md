# 🎨 AI 繪圖橫式萬年桌面月曆 (`ai-art-calendar`)

專為展示個人 AI 繪圖作品並結合日常行事管理的 **橫式萬年桌面月曆 & PWA 漸進式網路應用程式**。

- 🌐 **線上 PWA 網址**：[https://famidoc.github.io/ai-art-calendar/](https://famidoc.github.io/ai-art-calendar/)

## ✨ 核心特色

1. **黃金視覺比例（上 2/3 AI 繪圖 ＋ 下 1/3 月曆格）**
   - **月曆模式**：嚴格維持上半部 2/3 展示當月 AI 繪圖、下半部 1/3 為緊湊高質感的日期網格。
   - **週曆 / 日曆平滑延展**：當點擊左側週選單（`W1 ▸` ~ `W6 ▸`）或點擊任一日期格時，下方毛玻璃記事面板會平滑向上展開至 73%，退回月曆時再自動恢復 2/3 畫作比例。
2. **萬用年曆引擎（自動跨年農曆、生肖、24 節氣、台灣國定假日與補假）**
   - **自由切換年份**：頂部工具列可切換任意西元年份，並提供「📍 今日」一鍵跳回當天。
   - **自動曆法推算**：自動計算任意年份的天干地支與生肖（如 2026 丙午馬年、2027 丁未羊年、2028 戊申猴年）、農曆初一十五、除夕、春節、元宵、端午、七夕、中元、中秋、重陽、二十四節氣與台灣國定假日逢週末補假規則。
   - **彈性放假手動微調**：在「日曆」視圖中點選「🏖️ 調整休假/補班」，即可將任意一天手動標記為休假紅字或補班日。
3. **每年 12 個月獨立保存專屬 AI 繪圖**
   - **直接拖曳換圖**：將電腦或手機裡的 AI 繪圖直接拖曳到月曆上半部（或點「🖼️ 換圖」），系統會依**「年份-月份」**獨立保存（本機自動存為 `images/YYYY-MM.png`，例如 `images/2026-11.png`、`images/2027-01.png`；並相容既有 `01.png ~ 12.png` 作為 2027 年月曆圖）。
   - **還原預設圖與焦點微調**：各年份各月份皆可獨立調整「📐 滿版 / 🖼️ 完整」、「焦點滑桿」與左下角畫作題詞，亦可隨時點擊「↺」還原預設星雲畫布。
4. **三段式行事曆（月曆 ➔ 週曆 ➔ 日曆）**
   - **左側週選單 (`W1` ~ `W6`)**：點選即可檢視該週 7 天的行程、待辦與備忘總覽，並可填寫「🎯 本週重點備忘」。
   - **日曆三大分區結構**：
     - **🕒 行事安排 (Schedule)**：可設定時間、內容與 5 種分類顏色標籤，自動同步顯示在月曆與週曆格子上。
     - **☑️ 待辦事項 (To-Do List)**：可打勾完成的核取清單，顯示完成進度。
     - **📝 註記與隨筆備忘 (Memo & Notes)**：自由書寫的文字區，打字即時自動存檔。
5. **PWA 支援 ＋ IndexedDB 大容量儲存（可分享給親朋好友）**
   - 內建 [`manifest.webmanifest`](./manifest.webmanifest) 與離線快取 [`sw.js`](./sw.js)，支援電腦（Edge / Chrome 獨立視窗安裝）與手機／平板（iOS / Android 加到主畫面）離線使用。
   - 採用瀏覽器 **`IndexedDB` 大容量資料庫** ＋ 本機 `server.mjs` 雙引擎儲存，親友在自己手機或電腦上傳再多高畫質 AI 圖片都不會爆容量，且各自資料儲存在自己裝置上互不干擾。

## 🚀 本機啟動方式

- **方式一（推薦，零黑窗快速啟動）**：雙擊 [`無黑窗啟動桌面月曆.vbs`](./無黑窗啟動桌面月曆.vbs) 或 [`啟動AI萬年桌面月曆.bat`](./啟動AI萬年桌面月曆.bat)。
- **方式二（啟用完整無邊框 Electron 釘選置頂模式）**：首次執行一次 [`安裝無邊框Electron模式.bat`](./安裝無邊框Electron模式.bat)，之後啟動即會以完全無邊框、支援釘選最上層 (`📌`) 的原生桌面 Widget 執行。
