# AI 萬用年曆 (AI Art Calendar) 記事寫入技能

本技能負責將使用者口述或輸入的 **[行事安排]**、**[待辦事項]**、**[註記與隨筆備忘]** 及 **[本週重點備忘]**，轉換為結構化參數並產生「一鍵寫入雲端連結」，同步至張醫師的「AI 萬用年曆」（手機 PWA 與電腦桌面版雙向同步）。

---

## 一、三大欄位與參數規範

雲端寫入端點（Google Apps Script 網頁應用程式）：
```
https://script.google.com/macros/s/AKfycbw52alTyL-zPAYH6GKJHb3vED2smOanSX7W2BdiRdRQWJgvv0nrvIe9MLKdyHsJueqD/exec
```

支援的 URL Query 參數如下：

1. **`date`（必填，日期）**：
   - 格式：`YYYY-MM-DD`（例如 `2026-11-18`）。
   - 若使用者說「今天」「明天」「下週三」，請根據當下日期自動換算為精確的 `YYYY-MM-DD`。

2. **`sched`（選填，🕒 行事安排 Schedules）**：
   - 單筆格式：`開始時間~結束時間|行程內容|顏色標籤` 或 `開始時間|行程內容|顏色標籤`
   - 多筆格式：以分號 `;` 分隔多筆行程。
   - **顏色標籤 (`color`) 支援 5 種**：
     - `sky`（預設，天藍：一般行程、門診、日常安排）
     - `emerald`（翠綠：運動、單車、健康、休閒）
     - `amber`（琥珀黃：提醒、教學、演講、進修）
     - `rose`（玫瑰紅：重要會議、急件、截止日、聚餐慶典）
     - `violet`（紫羅蘭：靈感、AI 創作、寫作、個人計畫）
   - 範例：`09:00~12:00|門診看診|sky;14:00~16:00|衛生局會議|rose`

3. **`todo`（選填，☑️ 待辦事項 To-Do List）**：
   - 格式：多筆待辦事項以分號 `;` 分隔。
   - 範例：`準備演講簡報;印會議講義;買高鐵票`

4. **`memo`（選填，📝 註記與隨筆備忘 Memo & Notes）**：
   - 格式：自由文字段落（預設會自動換行附加在該日既有備忘下方，不會覆蓋舊備忘）。
   - 若使用者明確要求「覆蓋/取代原本備忘」，可額外加上 `&memoMode=overwrite`。

5. **`weekKey` 與 `weekMemo`（選填，🎯 本週重點備忘）**：
   - 當使用者特別指定「本週重點」時使用，例如 `weekKey=2026-11-W2&weekMemo=完成年度計畫報告`。

## 二、回覆使用者的標準格式（在 Gemini App 中）

當使用者要求將行程、待辦或備忘記入萬用年曆時，請依下列步驟回應：

### 步驟 1：清楚列出整理後的預覽清單
以簡潔易讀的條列確認即將寫入的內容：
- **📅 日期**：`YYYY-MM-DD (週X)`
- **🕒 行事安排**：列出時間、內容與對應顏色
- **☑️ 待辦事項**：列出待辦項目
- **📝 註記備忘**：列出備忘文字

### 步驟 2：產生「一鍵寫入 AI 萬用年曆」超連結
將參數進行標準 URL Encode（確保中文與符號正確編碼），組合成完整 Markdown 可點擊連結：

```markdown
👉 **[📅 點此一鍵寫入 AI 萬用年曆](https://script.google.com/macros/s/AKfycbw52alTyL-zPAYH6GKJHb3vED2smOanSX7W2BdiRdRQWJgvv0nrvIe9MLKdyHsJueqD/exec?date=YYYY-MM-DD&sched=...&todo=...&memo=...)**
```

> **重要規則**：
> - 連結中的查詢參數值（尤其是中文、空白、`|`、`;`、換行）請務必進行 URL 編碼（Percent-encoding），避免連結斷裂。
> - 若某欄位使用者未提及（例如只有待辦事項、沒有行事安排），則省略該空白參數即可。
> - 點擊該連結後，雲端網頁會**自動執行寫入**，使用者無須再按第二次儲存按鈕。
