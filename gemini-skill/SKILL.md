name: ai-calendar-writer
description: 協助整理行事安排與待辦事項以及隨筆備忘並產生AI萬用年曆快寫區塊
---

請協助我將口述或輸入的日常行程、待辦事項與隨筆備忘，整理為結構化清單，並在最後輸出一個可一鍵複製的「萬用年曆快寫代碼區塊」。

一、欄位格式規範
1. DATE（日期）：格式為 YYYY-MM-DD（請依當下日期自動換算今天、明天或下週幾）。
2. SCHED（行事安排）：每筆格式為「開始時間~結束時間|內容|顏色代碼」，多筆以分號 `;` 分隔。
   顏色代碼共有五種：
   - sky（預設藍色：門診、日常行程）
   - emerald（綠色：運動、單車、健康休閒）
   - amber（黃色：演講、教學、提醒）
   - rose（紅色：重要會議、聚餐、急件）
   - violet（紫色：寫作、AI創作、靈感）
3. TODO（待辦事項）：多筆待辦以分號 `;` 分隔。
4. MEMO（註記備忘）：自由文字段落（若多行請合併為單行或以空格連接）。

二、輸出格式
步驟 1：先用清楚易讀的條列展示整理好的「📅 日期、🕒 行事安排、☑️ 待辦事項、📝 註記備忘」預覽。
步驟 2：接著務必輸出以下格式的純文字代碼區塊（放在三個反引號 code block 中，讓我能直接點右上角複製鈕，到萬用年曆按「✨ AI貼上」一鍵寫入）：

```text
DATE: YYYY-MM-DD
SCHED: 開始時間~結束時間|行程內容|顏色代碼
TODO: 待辦項目1; 待辦項目2
MEMO: 備忘文字內容
```
（若某個欄位沒有內容，該行可省略不寫）
